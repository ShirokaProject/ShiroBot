# 1.0.0

<ReleaseMeta />

## 更新内容

- 新增 `Context.CreateTempDirectory`：插件声明保留时长，由宿主负责清理，异常退出留下的文件会在下次启动时清理。
- 同一个宿主目录只允许运行一个进程，避免误删另一个进程正在使用的临时文件。
- 适配器启停、重载和更新时，插件实例和事件订阅保持不变；旧程序集无法释放时提示重启，更新包在下次启动时应用。
- 更新插件和适配器时保留用户配置、Cookie 和包外的文件；发布包不再包含调试符号。
- 配置界面可以读取共享程序集中的配置类型，正确显示字段名称、说明、分组和密码输入框。
- 修复宿主主题设置和配置热更新；改进 Avalonia 渲染中文与数字时的字体对齐。
- 开发模板调整为源码放在 `src`、脚本放在 `scripts`，运行和调试共用同一份宿主配置，Debug 下支持 Avalonia 预览。
- 内嵌 Dashboard 更新为 1.0.0，可用 `api.enable_dashboard` 关闭。

## 升级说明

- API 配置统一到 `[api]`，使用 `token`、`listen_urls` 和数组形式的 `public_base_url`。旧的 `[api.auth]` 已移除且不会自动迁移，请手动改写。
- API 鉴权始终开启，必须设置令牌。
- 插件开发使用 `ShiroBot.SDK` 和 `ShiroBot.Templates` 1.0.0。
- Milky 适配器停止时初始化请求无法取消的问题已在 Milky 2.2.5 修复，请一并更新。

## 已知问题（Windows）

- .NET 10.0.12 及更早版本在同一进程中反复卸载、加载适配器时，可能卡在配置初始化，见 [issue #5](https://github.com/ShirokaProject/ShiroBot/issues/5)。遇到时重启宿主，或先停止宿主再替换适配器。
- .NET 10.0.13 已修复。非自包含版装上新运行时并重启即可；自包含版和 Docker 镜像需要等使用新运行时重新构建的版本。
