# 1.0.5

<ReleaseMeta />

对比 1.0.4。

## 主要更新

- 宿主和 Dashboard 同步为 1.0.5；SDK ABI 与 QQ、Discord、Telegram Model ABI 不变。
- 消息触发前缀可以设置多个，带上任意一个即可触发；同时能匹配多个时取最长的。Dashboard 中以标签形式编辑，配置文件里仍是用空格分隔的一个字符串。
- 设置了全局前缀就要求前缀，去掉了单独的「要求前缀」开关；带前缀的消息去掉前缀后再交给插件，命令、整条消息监听和插件自己的解析看到的是同一段文本。
- 插件单独设为「要求前缀」后，没带前缀也没有 @ 机器人的消息一律不交给它，链接解析这类自动触发也不例外；跟随全局时只有命令要求前缀，自动触发照常工作。
- 自动更新先更新宿主，重启后再更新插件和适配器，最后给 Owner 发一条汇总，附上宿主这个版本的更新日志；需要重启才生效的插件和适配器更新，在重启后（包括手动重启）汇报结果。
- Dashboard 关于页可以展开查看宿主更新日志；宿主更新后第一次打开 Dashboard 会弹出一次这个版本的更新内容。
- 插件页和适配器页的自动更新卡片加入「检查更新」，显示可更新数量和上次检查时间。
- 启动适配器实例时自动启用它所属的适配器包，Dashboard 不再单独显示适配器包开关。
- 保存 API 监听地址和外部基础 URL 时校验格式，无效地址会被拒绝并指出是哪一个；`config.toml` 里写错的监听地址在启动时跳过并给出警告，不再导致宿主无法启动。API 设置项改为中文名称。
- Dashboard 手机布局改为悬浮底栏，向下滚动时隐藏顶栏；通过 `?token=` 链接登录后可以选择记住密钥；同一个后端地址可以用不同名称重复添加；切换后端时有过渡动画。

## 修复

- 更新已禁用的插件时原地替换并保持禁用，不再被重新启用。
- Dashboard 从「发现」切回「已安装」时，选中高亮不再停在旧位置；中等宽度下左侧导航不再随页面滚走；窗口较矮时侧栏按钮不再错位，也不再同时出现两个高亮。
- Dashboard 日志视图在快速滚动和跳转时保持跟随最新日志；插件分类筛选换行时每个分类各占一块。

## 升级说明

- 之前设置了全局前缀但没有打开「要求前缀」的，升级后会开始要求前缀。不需要前缀的话清空全局前缀，或把个别插件设为「不要求前缀」。
- 已单独设为「要求前缀」的插件，升级后没有前缀的消息不再进入它的整条消息监听和自定义判断（例如 MyParser、GitHubView 的链接解析）。希望它们照常自动触发，请改回「跟随全局」。
- 前缀按空格分隔，原来中间带空格的前缀（如 `hey bot`）会被当作两个前缀。
- 插件和适配器无需重新构建。
