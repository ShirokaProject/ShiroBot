# 1.0.1

<ReleaseMeta />

## 更新内容

- 插件从独立的影子 DLL 加载，修复更新后重载仍运行旧代码的问题。
- 旧程序集未释放、文件清理失败或更新已暂存时提示重启；清理失败的目录会在下次启动时重试。适配器同样适用，删除适配器后未完成的清理提示仍会保留。
- 内嵌 Dashboard 更新为 1.0.1，插件页和适配器页分别显示各自的重启提示。
- 改善插件热卸载，加快 Dashboard 插件列表的刷新。
- 宿主默认使用 Workstation GC，渲染图片直接写入文件，降低内存占用。
- 修复替换 TOML 配置表时 CRLF 换行产生空行的问题。
- 开发模板发布前检查程序集版本与 tag 是否一致；改进 Docker 以非 root 用户运行和缓存目录的写入权限。

## 升级说明

- SDK 和各 Model 的 ABI 不变，现有插件和适配器可以直接使用。
- `ShiroBot.SDK` 和 `ShiroBot.Templates` 同步为 1.0.1。
- 非自包含版需要 ASP.NET Core 10 Runtime 10.0.13 或更新；自包含版和 Docker 镜像已内置新运行时。旧运行时反复重载适配器可能卡住，见 [issue #5](https://github.com/ShirokaProject/ShiroBot/issues/5)。
