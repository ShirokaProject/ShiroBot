## 快速开始

从 [Releases](https://github.com/ShirokaProject/ShiroBot/releases) 下载安装包运行，或使用 Docker 部署，详见[安装与启动](https://docs.shiroka.org/guide/installation)。  
启动后打开 `http://127.0.0.1:7001/dashboard/` 就能看到控制面板啦～  
登录密钥在启动日志里，记得找一下哦 (｡･ω･｡)ﾉ

## 开发插件与适配器

开发方式见[插件开发](https://docs.shiroka.org/plugin/)和[适配器开发](https://docs.shiroka.org/adapter/)文档。  
完成后欢迎到 [awesome-shirobot](https://github.com/ShirokaProject/awesome-shirobot) 提交 PR，收录你的插件或适配器。

## 参与开发

欢迎参与 ShiroBot 本体的开发。仓库结构、源码构建与文档预览见[从源码构建](https://docs.shiroka.org/guide/development)。
